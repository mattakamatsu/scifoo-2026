# Modular Attribution × Open Science 2.0

Session notes from Sci Foo Singapore 2026 (15 November 2026), published at
https://mattakamatsu.github.io/scifoo-2026/

A single static page (`index.html`) built from the session whiteboard and transcript. The board stays pinned while you read. It opens as the photo (`whiteboard.webp`) and fades into a transcription (`transcribed.webp`, exported from Figma), and a ring highlights the part of the board each section covers.

The page carries a `noindex` tag so search engines skip it. Delete that line in `index.html` once attendees are fine with the quotes being public.

Quotes are from the session transcript, trimmed of false starts and left unattributed.
